# 语法道场（Grammar Dojo）

面向日语学习者的个人语法学习闭环工具——**写句即批改，错误必沉淀，考点可标记，复习有重点**。

通过「造句 → AI 批改 → 错误本 → 加权测试」的完整闭环，把每一次造句练习都转化为可积累、可复习的学习资产。备考 J.TEST / JLPT 均适用。

## 功能总览

| 模块 | 说明 |
|---|---|
| **校对练习** | 提交一句日语，返回三档判定（正确／不自然／有误）、错误高亮（错误→正确）、原因与避免建议、中文译文 |
| **考点识别** | 同步识别句中的 J.TEST 考点语法条目（如「〜以来」「〜あまり」），含中文释义、接续说明、易混条目；正确句同样识别 |
| **接续复核** | 本地确定性规则 + 专项校验两段流水线：教科书级接续误用（如「た形＋以来」）保证命中并自动给出修正 |
| **语法笔记** | 点击考点条目即可标记收藏，按语法点自动归组；相似语法自动聚类，支持 AI 辨析对比表（意思／接续／核心区别／例句） |
| **句库** | 所有句子自动存档，支持筛选、搜索、按语法点筛选、JSON 导出/导入备份 |
| **错误本** | 判「有误」自动收录，错误率 = 累计答错 ÷ 累计出现；掌握状态三档自动流转（未掌握/巩固中/已掌握） |
| **测试** | 按错误率加权出题（错得越多考得越勤），改错/选择/填空三题型，答错轮内重测直到答对，结果实时回写错误本 |

## 快速开始

1. **启动本地服务**（解决浏览器 CORS 限制，同时托管应用）：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File serve.ps1
   ```

   然后访问 <http://127.0.0.1:8765/>

2. **配置校对引擎**：在应用「设置」页选择服务商（默认智谱 GLM，模型 `glm-4-flash` 免费），填入 API Key（[open.bigmodel.cn](https://open.bigmodel.cn) 获取），点「测试连接」。也支持任意 OpenAI 兼容端点。

   > 未配置 Key 时可点「演示结果」体验完整流程。

3. **开始练习**：校对练习页输入一句日语（Ctrl+Enter 提交）→ 查看批改 → 点击「下一句」继续。

## 技术实现

- **纯前端单文件应用**（`app/index.html`）：HTML/CSS/JS，无构建依赖，数据存于浏览器 localStorage
- **本地服务**（`serve.ps1`）：PowerShell HttpListener，托管静态文件 + API 转发（绕开浏览器 CORS）+ `Cache-Control: no-store`
- **校对引擎**：大模型 API（OpenAI 兼容 Chat Completions，结构化 JSON 输出 + 健壮解析层）
- **可靠性设计**：本地确定性接续规则（不依赖模型）→ 权威语法条目库 → 全量事实核查 → 模型原始输出，四级优先级
- **测试**：冒烟测试准则（交互自带实现 + 真实浏览器验证）
